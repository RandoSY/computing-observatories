# CRCL v0.6.1 Classroom Workspace

CRCL now starts in **Simple View**. The default classroom screen intentionally contains two dominant panels:

1. **WRITE CRCL** — the Forth-like program editor, immediate console, RUN, STOP, WORDS, and GLOSSARY.
2. **WATCH THE ROBOT** — the Robot Digital Twin / Reality Pane.

This restores the original teaching metaphor: write instructions on the left and watch the virtual or physical robot act on the right.

## Staged tools

Press **MORE TOOLS** to reveal the full platform: Dashboard, Glossary, Vocabulary manager, MakeCode Harvester, Reality Views, Automation, Python Workshop, Wireless Deploy, Serial/REPL, Debug, Setup, generated CircuitPython, and target controls. Press **SIMPLE VIEW** to return to the two-panel classroom surface.

## Larger text

The default text is substantially larger than v0.6.0. Use **A−** and **A+** in the top bar to select one of three classroom font sizes. The setting is saved locally in the browser.

## Design rule

Advanced capability is preserved, but complexity is not presented until the learner or instructor asks for it. The default visual hierarchy is intentionally:

`CRCL source  ↔  robot/reality`
