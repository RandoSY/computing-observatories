# Before the Click · Classroom Kit v2

Explore four interactive computing systems from 1962–1973: the LINC, Apollo DSKY, DEC GT40, and Xerox Alto. A fifth station uses simulated data or a USB serial microcontroller to connect the historical lessons to live physical computing.

- [Read the setup instructions](START_HERE.txt)
- [Browse the standalone lab HTML](Before_the_Click_Lab.html)
- [Student Fieldbook (PDF)](Student_Fieldbook.pdf)
- [Teacher Guide (PDF)](Teacher_Guide.pdf)

To run the lab offline, extract the ZIP and open `Before_the_Click_Lab.html` in Chrome or Edge. Stations 1–4 and the Station 5 simulator require no hardware.
